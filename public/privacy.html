Privacy

Street Food Rush does not create its own accounts and does not ask for your name, email, phone number or location.

Inside Lagos Life, the game receives only what the Vatar Games SDK provides for this game: a pseudonymous player id, display name, avatar and a short-lived session. That information stays in the game session. It is not sold or combined with another service.

Practice mode stores one personal best in this browser under the key street-food-rush-local-best. Clearing site data removes it.

When the cosmetic purchase server is configured, it stores the pseudonymous player id, the product id and the purchase id needed to deliver the Ankara counter once. It does not store a username, email, location or payment card.

A player record can be deleted by sending POST /players/delete to the game server with the server secret and the pseudonymous player id. This supports a request under the Nigeria Data Protection Act 2023.
