# Vatar sandbox — keep-it-running

## One command (after tunnels restart)

```bash
npm run sandbox:host
```

Copy URLs from `review/current-urls.env` into **Dashboard → Listing → Save listing**.

## Manual stack (current stable URLs)

| Role | URL |
|------|-----|
| Game / server / webhook | See `review/current-urls.env` (regenerated by `npm run sandbox:host`) |

Processes on this machine: `vite preview` (:4173), `npm run server` (:8080), two `cloudflared` tunnels.

## Finish checklist in sandbox

If the iframe looks black, click **Reload game** once or twice (Vatar’s iframe can load before height is known; the build uses `100vh` sizing for embedded play).

1. [Sandbox](https://lagoslife.app/developers/sandbox/5235c4c07523460eb888) → **Reload game**
2. Tap **Ankara counter** on the menu (above **Start shift**), confirm the test purchase sheet, then wait for the unlock banner.
3. Optional: **Dashboard → Build → Send test webhook** (already passed if you see ✓ on the Build tab).
4. Or automate after one-time login: `npx playwright test e2e/lagoslife-auth.setup.ts --project=lagoslife-auth --headed` then `npx playwright test --project=vatar-sandbox`.
